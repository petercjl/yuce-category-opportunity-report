# 预策类目机会研究

独立维护和发布的类目研究能力包。业务方法、模板与脚本以本包的 Skill 为唯一来源。

```sh
yuce-category-research skill source --json
yuce-category-research skill install --agent codex --json
yuce-category-research doctor --json
yuce-category-research script build_report.py --help
```

支持 Excel 输入及经授权的 NAS/预策取数，输出体量与增长分析和双视图 HTML。账号、yccli、tbcli 与服务访问在包外准备。Python 依赖见 requirements.txt。SealSeek/Windows 适配仍须真实宿主验证。员工可通过淘宝AI运营套件统一安装更新。
